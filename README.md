# Site institucional | Grupo Dactel, Autorizada Motorola RJ

Site estático com 4 páginas (Home, Nossas Lojas, Quem Somos e Contato), responsivo para desktop e mobile.

## Como publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos desta pasta para a raiz.
2. Em Settings, Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Estrutura
- `index.html`: Home
- `nossas-lojas.html`: unidades, horários, galeria e mapa
- `quem-somos.html`: institucional
- `contato.html`: telefones e rotas por unidade
- `img/`: fotos das fichas do Google, logo e imagem da hero
